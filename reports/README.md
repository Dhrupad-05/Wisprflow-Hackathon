# Verification reports

## Reports index

- `phase-0.md` through `phase-7.md`: phase reports and gate evidence.
- `phase-8.md`: hardening report; it records the remaining axe-core and throttled-CDP limitations.
- `eval-test.md`, `eval-test.json`, `eval-test-confusion.csv`: held-out routing evaluation.
- `screenshots/`: browser screenshots generated by Playwright tests when present.

Refresh local numbers with:

```powershell
pytest -q
python tests/eval/run_eval.py --split test
```

Provider credentials and axe-core are environment-dependent. Reports explicitly mark those checks as not verified live when they are unavailable.
