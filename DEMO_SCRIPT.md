# Three-minute demo

1. Start the server, open `http://127.0.0.1:8000`, and point out the DEMO MODE banner and consent notice.
2. Type `Ami chashi, amar loan lagbe`, choose `SBI`, then change your mind with `Na, taka jama dite chai`.
3. Enter `one two three four five six seven eight nine zero one`, confirm it, enter `paanch hazaar`, and confirm it.
4. Review the summary. Explain that only an explicit `haan` reaches submission; before that, use `nahi` once to demonstrate correction.
5. At the OTP step, type `123456` directly into the demo portal and select `I'm done`; the assistant never receives or stores it.
6. Enable private mode and open the masked activity log. Point out that this is a mock portal, not a real bank.
